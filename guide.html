Getting started

How ARQORA works.

A quick tour of the platform — from creating your first project to tracking construction on site.

Contents

1. Getting started 2. Create a project 3. Tasks & issues 4. Documents & drawings 5. Site & construction 6. Budget & BOQ 7. Team & approvals 8. Offline mode

1. Getting started

When you open the ARQORA workspace, you'll land on the dashboard. It gives you an overview of all active projects, overdue tasks, pending approvals, and recent activity across your studio.

Tip: Use the search bar (or press Ctrl+K / Cmd+K) to instantly find any project, task, drawing, or document.

Navigation

  • Sidebar (left) — switch between Dashboard, Projects, Calendar, Tasks, Documents, Team, Reports, and Settings.
  • Top bar — search, notifications, sync status, and quick-add button.
  • Mobile — tap the menu icon to open the sidebar, or use the bottom navigation bar.

2. Create a project

Every project in ARQORA goes through an 8-step wizard that captures all the essential details up front.

1

Project details

Name, code, type (Residential, Commercial, etc.), and description.

2

Client

Client name, company, email, and phone.

3

Site

Address, city, country, and GPS coordinates for site navigation.

4

Schedule

Start date and target completion date.

5

Budget

Estimated budget and currency.

6

Team

Assign a project manager and team members.

7

Brief

Objectives, requirements, and constraints.

8

Review & create

Review all details and create the project.

Tip: You can edit any project detail later from the project's Overview tab.

3. Tasks & issues

Tasks

Tasks are the day-to-day work items. Each task has a title, assignee, due date, priority, and status. You can view tasks within a project or across all projects from the global Tasks page.

To create a task, click the Add button (or the floating + button on mobile) and select Task.

Issues

Issues track problems that need resolution — design conflicts, site defects, or anything blocking progress. Each issue has a status (Open, In Progress, Resolved, Closed) and can be linked to a specific project.

RFIs

Requests for Information let you formally ask questions about the design or scope. Each RFI has a number, subject, status, and response.

4. Documents & drawings

Documents

Upload and organize project documents — contracts, permits, specifications, reports. Each document has a category and can be linked to a project.

Drawings

Track drawing revisions with a number, title, revision, and status (Draft, Review, Approved, Superseded). The system keeps a full revision history so you always know which version is current.

Tip: Use the global Documents page to search across all projects at once.

5. Site & construction

Site diary

Record daily site activity — weather, workforce, equipment, progress notes, and incidents. Site diaries are timestamped and linked to the project.

Photos

Log site photos with captions and categories. Photos appear in the project's Photos tab and can be referenced in site diaries.

Progress tracking

Update construction progress by section or phase. The progress bar on the project overview reflects the latest updates.

Inspections

Schedule and record inspections with a status (Pending, Passed, Failed, Re-inspection) and inspector notes.

Site mode

Tap Site mode in the user menu to switch to a field-optimized layout with quick access to diary, photos, and progress.

6. Budget & BOQ

Budget

Track budget items with estimated, committed, and actual costs. The budget summary shows total estimated vs. actual spending per category.

BOQ / RAB

The Bill of Quantities (RAB in Indonesian) lists every item with a code, description, category, quantity, unit, and unit price. The system calculates the total project value automatically.

Change orders

Document changes to scope or budget with a status (Draft, Submitted, Approved, Rejected) and the cost impact.

7. Team & approvals

Team

Invite members to your workspace and assign roles (Owner, Admin, Member). Each member's active task count is visible on the Team page.

Approvals

Submit items for approval (drawings, change orders, payments). Approvers see pending items on the dashboard and can approve or reject with a comment.

Discussions

Each project has a discussions tab for threaded conversations. Keep design decisions and project communication in one place.

Calendar

The global calendar shows all deadlines, milestones, and task due dates across projects in a monthly view.

8. Offline mode

ARQORA is designed to work fully offline. Your data is stored locally in your browser, so you can create tasks, write site diaries, and update progress even with no internet connection.

How it works: When you're offline, a banner appears at the top. Your changes are saved locally and sync automatically when you reconnect. Check the sync status in the top bar or the user menu.

Sync status

Click the sync indicator in the top bar to see pending changes, last sync time, and any failed items that need retrying.
